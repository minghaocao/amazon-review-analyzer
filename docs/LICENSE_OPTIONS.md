# License Options

No license has been selected for Amazon Review Analyzer. Until the owner explicitly chooses one, source availability alone does not grant reuse rights.

## MIT

Best suited to an open-source portfolio where broad reuse is welcome. MIT is short, permissive and allows commercial use, modification and redistribution with copyright and license notices retained. It provides no explicit patent grant.

## Apache License 2.0

Best suited to an open-source portfolio where an explicit patent license and clearer contribution terms are valuable. It is permissive but longer than MIT and requires preservation of notices and documentation of modified files in some distributions.

## Proprietary / All Rights Reserved

Best suited to a source-visible portfolio or private commercial prototype when the owner wants people to inspect the work but not automatically copy, modify or redistribute it. A concise `LICENSE_NOTICE.md` can state the permitted viewing or evaluation scope without granting an open-source license.

## Decision Guide

| Intended use | Practical choice |
|---|---|
| Open-source portfolio with maximum adoption | MIT |
| Open-source portfolio with explicit patent terms | Apache-2.0 |
| Source-visible portfolio with reuse restricted | Proprietary / All Rights Reserved |
| Private commercial prototype | Proprietary agreement reviewed for the intended business |

This document is decision support, not legal advice. Before public publication, the owner should select a license that matches the intended reuse policy and, when necessary, obtain legal advice. Step 17 intentionally does not create a final `LICENSE` file.
