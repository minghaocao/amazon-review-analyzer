# Sample Reports

These four standalone HTML files demonstrate the two report types and both supported display languages in Amazon Review Analyzer v1.0.0.

| File | Report type | Language |
|---|---|---|
| `single_product_report_en.html` | Single-product business report | English |
| `single_product_report_zh_CN.html` | Single-product business report | Simplified Chinese |
| `competitor_comparison_report_en.html` | Two-product comparison report | English |
| `competitor_comparison_report_zh_CN.html` | Two-product comparison report | Simplified Chinese |

Open a file directly in a modern browser. Each report contains its own CSS and does not require localhost, a CDN, external fonts, JavaScript, or a live AI model.

The Amazon Quick Scan sample is a previously saved local analysis. It is included to demonstrate report presentation; it is not an official Amazon dataset and should not be treated as a statistically representative product assessment.
